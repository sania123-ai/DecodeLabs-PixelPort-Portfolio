# 🚀 PixelPort – Developer Portfolio

A modern and responsive static portfolio website built using **HTML and CSS** as part of the **DecodeLabs Frontend Development Internship (Week 1 Project)**.

---

## 📌 About the Project

PixelPort is a clean and modern developer portfolio landing page designed to showcase frontend development skills. It focuses on semantic HTML structure and modern CSS styling including glassmorphism effects.

---

## ✨ Features

- Responsive design
- Modern UI layout
- Glassmorphism style cards
- Clean and structured HTML
- CSS hover effects
- Professional portfolio sections

---

## 🛠️ Tech Stack

- HTML5  
- CSS3
